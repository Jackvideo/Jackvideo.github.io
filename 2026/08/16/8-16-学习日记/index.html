Python 开发基础复习

高铁上复习了一些 Python 开发里常见、但很容易“看着熟、写着忘”的内容，比如 typing、pydantic、pathlib、with 的用法等等。

其中比较有意思的是 typing.Protocol。

Protocol 可以理解成 Python 里的“结构化接口”。一个类不需要显式继承某个协议类，只要它拥有协议要求的属性和方法，静态类型检查器就可以认为它满足这个协议。

相比继承，Protocol 没有强耦合的父子关系，更适合用来表达“我只关心你能不能做这件事，而不关心你到底是谁”。

继续开发面试官 Agent

今天继续推进面试官 Agent 项目。

目前项目主要完成了“面试官 Agent”的基础闭环，目标是做一个用于学习 Agent 开发和 AI 工程实践的模拟面试系统。当前进度包括：

  • 使用 InterviewSession 管理会话状态、轮次和消息记录；
  • 使用 InterviewConfig 配置岗位、技术栈、级别和最大轮数；
  • 使用 InterviewAgent 实现开始面试、提交回答、追问和结束面试；
  • 使用 InterviewService 编排 Agent 与存储层；
  • 使用 ModelClient Protocol 抽象模型调用；
  • 提供 FakeModelClient，用于无 API 的本地测试；
  • 提供兼容 OpenAI Chat Completions 协议的 OpenAIModelClient；
  • 对限流、超时、连接错误和服务端错误做了可重试错误分类；
  • 使用 JSON 文件保存和恢复会话；
  • 提供 CLI 入口，可以通过 --session-id 恢复会话；
  • 已有 Service 和 Storage 的基础测试。
